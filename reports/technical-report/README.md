# Reporte técnico

El reporte está disponible como página web local en [`index.html`](./index.html)
y como fuente Markdown en [`index.md`](./index.md). La sección de datos para
PD y sus figuras se integraron desde el módulo `src/credit_risk/data/`.
Cuando GitHub Pages quede habilitado y se publique `main`, estará disponible en
<https://nicorb72.github.io/-Redes-neuronales-para-datos-tabulares/technical-report/>.
Las cifras y gráficas se identifican como pendientes de cotejar con `loan.csv`,
que no está incluido en el clon actual. El reporte se ampliará con resultados
de modelos, referencias verificables en APA 7, uso de IA y cacería de
alucinaciones con evidencia.
