# Riesgo de crédito con redes neuronales para datos tabulares

**Reporte técnico en formato de blog**

Este proyecto estudia la estimación de la probabilidad de incumplimiento (PD)
y la pérdida dado incumplimiento (LGD) en créditos de consumo. El equipo
integrará modelos de clasificación y regresión, una scorecard y una aplicación
web para presentar sus resultados.

## Integrantes

1. **[Nombre del integrante 1]** — Datos y análisis.
2. **[Nombre del integrante 2]** — Clasificación: probabilidad de
   incumplimiento (PD).
3. **[Nombre del integrante 3]** — Regresión: pérdida dado incumplimiento
   (LGD).
4. **[Nombre del integrante 4]** — Scorecard, interpretación y aplicación web.
5. **[Nombre del integrante 5]** — Integración, reproducibilidad y reporte.
