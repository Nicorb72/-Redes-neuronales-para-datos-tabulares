# Datos procesados

Guarden aquí la versión exacta de los datos que consumen los experimentos y
el código que la genera desde `data/raw/`. Incluyan metadatos sobre las
columnas, filas, periodo y transformaciones aplicadas.

Los artefactos procesados no están excluidos de Git: si el archivo supera los
límites del repositorio, acuerden una alternativa reproducible y documenten
cómo obtenerlo sin depender de APIs durante la ejecución.
